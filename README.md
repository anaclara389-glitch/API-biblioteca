# 📚 API Rest - Gerenciamento de Livros

Uma API RESTful simples desenvolvida em **Python** utilizando o micro-framework **Flask**. O objetivo deste projeto é simular o sistema de gerenciamento de uma biblioteca, permitindo realizar as operações básicas de um **CRUD** (Create, Read, Update e Delete).

---

## 🚀 Funcionalidades (C.R.U.D)

-  **Consultar todos os livros:** Lista o catálogo completo do acervo.
-  **Consultar livro por ID:** Busca os dados de um livro específico pelo seu identificador.
-  **Criar livro:** Adiciona um novo livro ao catálogo.
-  **Editar livro por ID:** Atualiza as informações (título e/ou autor) de um livro existente.
-  **Excluir livro por ID:** Remove um livro do acervo.
